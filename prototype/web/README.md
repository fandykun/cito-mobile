# Veterinary Clinic Management App Prototype

This directory contains the Vite/React visual prototype generated from the [Veterinary Clinic Management App Figma design](https://www.figma.com/design/0MHDMHs5bgTKUbtP97pmdu/Veterinary-Clinic-Management-App).

It uses mock data and is not the production client. Run workspace commands from the repository root:

```bash
npm ci
npm run prototype:dev
npm run prototype:build
```
